Herramientas Excel

Automatiza tareas tediosas en Excel con scripts rápidos y fáciles de usar.

Resumen

Este proyecto reúne herramientas para optimizar procesos repetitivos en Excel. Desde dividir hojas en archivos individuales hasta consolidar grandes volúmenes de datos en segundos, todo con la simplicidad de un clic.

Herramientas disponibles

Separar hojas de Excel

Un script que toma un archivo con múltiples hojas y genera un archivo por cada una automáticamente.

Ver en GitHub

Consolidar datos

Combina múltiples archivos Excel en un solo libro, organizando la información de manera ordenada.

Ver en GitHub
